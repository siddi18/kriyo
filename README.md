# 🛒 Shopping Cart Application

A modern, fully-functional shopping cart built with vanilla JavaScript, HTML, and CSS. No frameworks required!

## ✨ Features

- **20+ Products** across 4 categories (Electronics, Clothing, Books, Home & Garden)
- **Real-time Cart Management** with add, remove, and quantity updates
- **Smart Search & Filters** to find products easily
- **Sort Options** by price (low to high, high to low) and name
- **Persistent Storage** using LocalStorage - your cart survives page refresh
- **Checkout System** with form validation and order confirmation
- **Fully Responsive** design for mobile, tablet, and desktop
- **Modern UI** with gradient effects, animations, and smooth transitions
- **Tax & Shipping Calculation** (10% tax, free shipping over $100)

## 📦 Installation & Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/siddi18/kriyo.git
   cd kriyo
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - No build process or dependencies required!

3. **Start shopping**
   - Browse products
   - Add items to cart
   - Proceed to checkout
   - Complete your order

## 💡 Key Functionality

### Product Management
- Dynamic product rendering from JavaScript data
- Category-based filtering
- Real-time search functionality
- Multiple sort options

### Cart Operations
- Add products to cart with quantity tracking
- Update quantities with +/- controls
- Remove items individually or clear entire cart
- Automatic price calculations (subtotal, tax, shipping, total)

### Checkout Flow
- Form validation for customer details
- Payment information collection
- Order summary display
- Unique order ID generation
- Success confirmation screen

### Data Persistence
- Cart state saved to browser's LocalStorage
- Cart persists across page reloads
- Automatic cart restoration on page load

## 🎯 Features in Detail

### Smart Calculations
- **Subtotal**: Sum of all item prices × quantities
- **Tax**: 10% of subtotal
- **Shipping**: $10.00 (FREE for orders over $100)
- **Total**: Subtotal + Tax + Shipping

### Responsive Design
- Mobile-first approach
- Breakpoints for tablets and desktops
- Touch-friendly interface
- Adaptive layout for all screen sizes

### User Experience
- Smooth animations and transitions
- Glassmorphism effects on header
- Gradient color schemes
- Toast notifications for actions
- Modal windows for cart and checkout
